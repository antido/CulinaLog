# Task 11 — Search, SEO and Accessibility

## Goal
Improve discoverability and usability.

## Search
Search:
- recipe title
- recipe description
- ingredient
- category
- author
- forum topics

Filters:
- category
- difficulty
- cooking time
- newest
- oldest
- popularity

Use server-side queries and pagination.

Avoid SQL injection and N+1 queries.

## SEO
Recipe pages should provide:
- unique title
- meta description
- canonical URL
- Open Graph metadata
- Recipe structured data where appropriate

## Accessibility
Implement:
- semantic HTML
- form labels
- keyboard navigation
- visible focus states
- useful alt text
- accessible buttons
- adequate contrast
- mobile-friendly controls

## Acceptance Criteria
Search is efficient, recipe pages have basic SEO support, and major interfaces are keyboard/accessibility friendly.
