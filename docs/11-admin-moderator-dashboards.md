# Task 10 — Admin and Moderator Dashboards

## Goal
Create separate role-aware dashboards.

## Admin Dashboard
Display:
- total users
- total recipes
- published recipes
- draft recipes
- comments
- pending comments
- forum topics
- pending reports

Include:
- recent recipes
- recent comments
- recent users
- recent forum topics

Admin management:
- users
- roles
- permissions
- categories
- recipes
- moderation

## Moderator Dashboard
Display:
- pending comments
- reported content
- recent reports
- moderation activity

## Security
Use:
- authentication
- verified status where applicable
- Spatie permissions
- policies
- backend authorization

Do not rely on hiding navigation links.

## Acceptance Criteria
Admin and moderator capabilities are clearly separated.
