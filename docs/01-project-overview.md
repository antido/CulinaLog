# Task 00 — Project Overview and Implementation Rules

## Goal
Establish the Recipe Community Web App project requirements and implementation rules.

## Stack
- Laravel
- PHP
- MySQL
- Laravel Breeze
- Inertia.js
- React
- Tailwind CSS
- Spatie Laravel Permission

## Roles
- admin
- moderator
- user

## Core Modules
1. Authentication
2. Users and Profiles
3. Roles and Permissions
4. Recipe Categories
5. Recipes
6. Ingredients
7. Instructions
8. Comments and Replies
9. Reactions
10. Forum
11. Reports and Moderation
12. Notifications
13. Search
14. Admin Dashboard
15. Moderator Dashboard
16. Security and Testing

## UI Requirements
Create a modern, clean, minimal, responsive interface for mobile, tablet, and desktop.

## Development Rules
- Prefer Laravel conventions.
- Keep code beginner-readable.
- Use Form Requests for validation.
- Use Policies and Spatie permissions for authorization.
- Never rely on frontend authorization.
- Never trust browser-submitted ownership, role, permission, or moderation fields.
- Use reusable React components.
- Avoid unnecessary abstraction.
- Use database indexes and eager loading where appropriate.
- Write tests for security-sensitive functionality.

## Completion
Do not proceed as if the whole application is complete. This task only establishes the project baseline and implementation conventions.
